Angular 22 · Bootstrap 5.3 · CDK Dialog

Reactive Bootstrap modals for Angular

Open a modal, subscribe to the result. A thin, typed layer over Angular CDK Dialog with a Bootstrap shell, a standardized outcome model, and built-in confirm / alert dialogs.

Open the playground 
npm install ngx-modalieur @angular/cdk bootstrap

Subscribe, don't wire

show() returns an Observable. React in one subscribe — no modal ids, no global result bus.

Bootstrap without glue

The library wraps your component in .modal > .modal-dialog > .modal-content. You only render header, body, and footer.

Built-in confirm / alert

One-liners for the dialogs every app reimplements, plus observable-driven auto-close.

Playground

Tweak the configuration and open a real modal. The code updates as you go.
